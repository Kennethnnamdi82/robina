# BaseDrop Frontend

## Run
```bash
cd BaseDrop
npm install
npm run dev
```

The app expects:
- `VITE_API_URL` in `.env` (see `.env.example`)
- Backend running at `backend/` service URL

## Build
```bash
npm run build
npm run preview
```

## Source Layout
- `src/components`
- `src/pages`
- `src/hooks`
- `src/services`
- `src/utils`
- `src/assets`
