# RIVALS — Offline-first, dependency-free PLAYABLE vertical slice

Run `python -m http.server 8080` in this folder. Visit http://localhost:8080.

A live wallet, blockchain, npm, Socket.IO, Redis, Render, Vercel or worker is NOT required.

Included: Arena lobby, 3 character choices, 3 zones, moving playable character, mobile joystick, wall collisions, dash, melee attack, enemy bullets, health, hacking minigame, Vault Core, extraction, retry, local ghost, functional Vault Architect, exported/imported JSON levels and collectible art previews.

This browser demo is NOT an authoritative competitive service or paid NFT application. No account, mining action, ranking payout or onchain transaction is connected. Production gameplay should be ported to TypeScript/Phaser and integrated with actual server-verified runs.
