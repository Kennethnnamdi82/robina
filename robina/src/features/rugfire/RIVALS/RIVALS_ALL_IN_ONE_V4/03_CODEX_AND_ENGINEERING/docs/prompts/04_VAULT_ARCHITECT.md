# CODEX PHASE 4 — Player-built and validated vaults

Create a grid-based Vault Architect with walls, corridors, laser emitters, security drones, terminals, keycards, extraction, safe spawn, enemy/hazard caps, cosmetic decoration and undo/redo. Serialize to versioned JSON with strong server-side validation; require flood-fill reachability, spawn safety, no duplicate object IDs, budget limits and successful creator test run before publication.

Published vault versions must be immutable; edits create new versions and new record tables. Add vault reports, basic moderation and simple telemetry. Premium themes are visual only, never stronger traps. Demo video: create -> test -> publish -> raid -> view owner statistics.
