# Reference research & external asset expansion

The bundled art is new original procedural artwork. External asset providers below are **suggestions, not files included in this ZIP**.

1. Kenney Top-down Shooter — 580 assets, CC0 — https://kenney.nl/assets/top-down-shooter
2. Kenney UI Pack Sci-Fi — 130 interface assets, CC0 — https://kenney.nl/assets/ui-pack-sci-fi
3. Kenney Isometric Dungeon Tiles — over 70 tiles, character sprites and Tiled samples, CC0 — https://kenney-assets.itch.io/isometric-dungeon-tiles
4. MurphysDad Sci-Fi Facility — 4-direction sprites, futuristic facility tiles and animated props, CC0 — https://murphysdad.itch.io/sci-fi-facility
5. Phaser tilemap technical docs — https://docs.phaser.io/phaser-editor/scene-editor/game-objects/tilemap-object

For best results, do not indiscriminately mix disparate pixel densities and isometric vs orthogonal perspectives. If using isometric tiles, replace/redo maps and coordinate math; the bundled maps are *orthogonal*. Keep a provenance and license record for every added asset. A CC0 asset pack is not a license to use its creator's trademarks.
